# ⚔️ 블레이드 아레나: 듀얼 오브 스틸 (Blade Clash Arena)

웹 브라우저에서 바로 즐길 수 있는 1대1 대전 액션 웹 게임입니다.  
1인용(vs AI) 및 2인용(로컬 1P vs 2P)을 완벽 지원하며, **궁수 / 검사 / 핵폭탄 3대 직업 시스템**, 플레이어 조작키 자유 리바인딩, 칼 스킨 커스터마이징, 막기(가드) 및 점프, 마우스 휠 화면 축소/확대, 그리고 **실제 LLM API 연동 챗봇('인증됨' 표시 지원)**을 탑재하고 있습니다.

---

## 🎮 주요 기능

### 1. 🛡️ 3대 전투 직업 선택 시스템 (시작 전 선택)
게임 시작 전이나 상단의 **`🏹 직업 선택`** 버튼을 눌러 1P와 2P(AI)의 직업을 각각 자유롭게 선택할 수 있습니다:
- 🏹 **궁수 (Archer)**:
  - **원거리 특화**: 활을 들고 고속 에너지 화살을 발사하여 원거리에서 적을 요격합니다.
  - `[공격(J)]` 단발 화살 발사
  - `[특수(K)]` 3연발 관통 화살 발사
  - `[막기(L)]` 회피 덤블링 (무적 구르기 기동)
- ⚔️ **검사 (Swordsman)**:
  - **정통 근접 검술**: 묵직하고 예리한 칼날로 상대를 베어 넘깁니다.
  - `[공격(J)]` 3단 연속 베기 콤보
  - `[특수(K)]` 전방 회전 돌진베기
  - `[막기(L)]` 육각형 홀로그램 실드 가드 (대미지 88% 경감)
  - `🗡️ 칼 스킨 공방`을 통한 무기 외형 커스텀 100% 지원!
- ☢️ **핵폭탄 (Nuker)**:
  - **자폭 & 초재생 특화**: 일반 무기 공격이 없으며, 오직 폭파와 피 회복만 존재합니다!
  - `[공격/특수(J/K)]` **폭파스킬 가동**: 시한장치를 가동한 뒤 **6초 동안 생존하여 버텨내면** 화면 전체를 집어삼키는 **초대형 핵폭발이 터지며 자폭 승리**합니다!
  - `[막기/힐(L)]` **피 회복 스킬**: 전체 체력의 1/5 (20 HP)을 즉시 회복합니다. (쿨타임 3초!)

### 2. ⚡ 민첩한 1프레임 즉각 방향 전환
- 방향키(`A`/`D` 또는 `←`/`→`)를 누르는 즉시 딜레이 없이 캐릭터가 1프레임만에 180도 스냅 회전합니다.
- 점프 중이나 기동 중에도 즉각적인 방향 조준이 가능하며, 마우스 클릭 시에도 커서 방향을 향해 자동으로 몸을 돌립니다.

### 3. 🔑 실시간 LLM API 챗봇 & 「인증됨」 표시
- 우측 하단 플로팅 챗봇을 통해 실제 최신 AI 모델과 실시간 대화할 수 있습니다.
- **Google Gemini API** (`gemini-1.5-flash` 등) 및 **OpenAI API** (`gpt-4o-mini` 등) 완벽 지원!
- 챗봇 상단 `⚙️ API 설정`에서 키를 입력하고 `[키 검증 및 인증]`을 누르면 즉시 실제 서버와 통신하여 유효성을 검사합니다.
- **인증 완료 시**:
  - 입력창 옆 **`[✅ 인증됨]`** 네온 그린 뱃지 점등
  - 챗봇 헤더 상태 표시줄 **`🟢 [인증됨] Gemini AI 가이드`** 상시 표시
  - 상단 메뉴 버튼 **`💬 AI 챗봇 [인증됨 🟢]`**으로 한눈에 확인 가능
- API 키가 없어도 무료 오픈 LLM API(`free_llm`) 및 오프라인 내장 전술 엔진으로 즉시 대화 가능합니다.

### 4. ⌨️ 조작키 자유 변경 (Key Bindings)
- 상단 `⌨️ 키 설정` 모달을 통해 1P와 2P의 [이동], [점프], [기본 공격], [특수기], [막기/힐] 키를 원하는 키보드 키로 자유롭게 리바인딩할 수 있으며 로컬스토리지에 자동 보존됩니다.
- 기본 조작키:
  - **1P**: `A`/`D` (좌우 이동), `W` (점프), `J` (공격/폭파), `K` (특수기/폭파), `L` (막기/힐/덤블링)
  - **2P**: `←`/`→` (좌우 이동), `↑` (점프), `1` (공격/폭파), `2` (특수기/폭파), `3` (막기/힐/덤블링)

### 5. 🔍 마우스 화면 축소 / 확대 (Zoom & Pan)
- 마우스 휠을 아래로 굴리면 화면 축소(최대 55%), 위로 굴리면 화면 확대(최대 180%)
- 마우스 우클릭 드래그로 화면 시야 이동(Pan) 지원
